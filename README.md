# Football Booking System

## 📌 Overview

Football Booking System is a practice project for learning **.NET / C#** from beginner to advanced level.

The project simulates a real-world football field booking system where users can:
- register/login
- book football fields
- manage schedules
- calculate payments
- generate reports

This project is designed to help practice:
- OOP
- Collections
- LINQ
- Delegates
- Exception Handling
- Async/Await
- File Handling
- Database
- ASP.NET Core API
- Authentication
- Design Patterns
- Clean Architecture

# 🚀 Recommended Setup

## Create Project

```bash
dotnet new console -n FootballBookingSystem
```

or:

```bash
dotnet new webapi -n FootballBookingSystem
```

## Run Project

```bash
dotnet run
```
